Final Year Project In Progress

CyberGuard AI

A smart AI-powered security gateway and mobile control system that sits in front of a server as a shield. Traditional firewalls and security systems fail because of three core problems — thousands of false-positive alerts that hide real attacks, black-box AI that blocks traffic without explaining why, and desktop-only control that leaves admins helpless during 3 AM incidents. CyberGuard AI solves all three at once.

Real-Time Detection

4 combined ML techniques detect intrusions with far fewer false positives

Explainable AI (SHAP)

Human-readable explanations for every block decision — no more black-box guessing

Flutter Mobile App

Instant push alerts + one-tap attacker blocking from anywhere, anytime

Gateway Architecture

Transparent proxy layer — protects the main server without code changes

02
Academic · DSP Course

Stress Detection via Physiological Signals

A Digital Signal Processing course project that detects human stress levels by analysing physiological signals — including Heart Rate Variability (HRV), Galvanic Skin Response (GSR), and EEG data. Raw biosignals are pre-processed with bandpass filtering and noise removal, then key time-domain and frequency-domain features are extracted to classify stress vs. non-stress states using a machine-learning classifier.

Signal filtering & feature extraction
HRV & GSR analysis
ML-based stress classification
